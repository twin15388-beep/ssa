# CAM Main Hub v2.3.0 — что нового (всё из исходников, без записей)

За основу взяты только декомпилированные исходники, которые вы уже прислали — никаких новых прогонов с записью не потребовалось.

## Auto Parry (beta) — раздел «v2.3 actions»
- Триггер: у Моб/Босс NPC срабатывает `Animator.AnimationPlayed` (приоритет Action) в радиусе (по умолч. 14, слайдер 4–30). Движущиеся цели (>3 studs/s) пропускаются.
- Тап блока: нативный `Skills_1st` (hold по умолч. 0.35, слайдер 0.15–1). Кулдаун 0.9 (0.3–3).
- Калибровка: сначала пробует input-путь. Если после 3 тапов нет серверного подтверждения, автоматически переключается на прямой сигнал `server_skill_controller_signaler "Blocking","Hold"/"UnHold"` (протокол из записи v1.0). Если и это не подтверждается после 3 тапов — **автопауза с уведомлением** (паттерн безопасности).
- Подтверждение (ack): узел `Values/<вы>/Blocking` (значение 9) = блок принят сервером; дочки `Perfect`/`PerfectNpc` = идеальный парри (заполнение — решение сервера, честная обратная связь).
- Метрика на экране: taps / blocks / perfect + текущий метод + «server-confirmed» когда ack получен.
- Отпускание: release через hold-секунд; при STOP/Unload завершается `release("Skills_1st")`.

## Auto Training (beta) — два режима (по запросу «instant и default»)
- **Instant (win signal)** — шлёт ровно то, что сам клиент сообщает победе (декомпилированный `137_Client.lua`, строка 123): `training_signaler "StateChanged"` → через 0.35 c → `"Stop", true`. Действует, когда начинается любая тренировка (появляется `pause_gameplay`/`skill_stand_still`/`Training`). Задержка перед стартом — слайдер (0.5 c по умолч.).
- **Default (auto-play slider)** — не шлёт выигрышных сигналов: сам играет мини-игру (находит бегунок и целевую зону в `PlayerGui.Misc`, кликает только когда бегунок внутри зоны). Если бегунок/зону не распознал за 6 c — сообщение, сессия пропускается (не ломается).
- Режим переключается dropdown'ом. Метрика: win-сигналов отправлено / кликов по слайдеру.

## Ручные действия (только явные клики; авто-повторов трат/покупок нет и не будет)
- **Shop**: «Shop item name (exact)» + количество (1–25) → `PurchaseFromShop(name, amount)` (ReturnValue извещения нет — сервер не показывает клиенту). Кнопка с Ore: `PurchaseFromShopWithOre(name)`. Протокол — `072_SpinBuyComponent.lua` / `081_GridContent.lua`.
- **Loadouts**: имя → Save (1) / Load (2) / Rename (3, текст) — `HandleLoadoutActions` (`075_Individual.lua`). Save подтверждается (перезаписывает).
- **Muzan**: «Start Muzan Quest (Demon race)» → `MuzanLairAssign` — только когда стоите у лайра; кнопка отклонит, если квест уже Doing (если Quests-модуль доступен).
- **Ranked**: ключ доски/режима → Refresh board (`action="Board"`) / Claim (`action="Claim"`). Протокол — `106_RankedController.lua`.

## Честные оговорки (verified vs. mocked)
- Парри: весь цикл проверен в мок-среде (тайминги, калибровка, ack-слежка, авто-pause). Реальная частота «attakuйших» анимаций и точный Action-приоритет атак в игре — подтверждается игрой; если тап приходит раньше/позже — подкрутите hold/cooldown слайдерами.
- Instant-режим тренировки: это буквально то, что клиент шлёт сам при победе; сервер МОЖЕТ перепроверять время от старта. Если не засчитывает — переключитесь на Default.
- Default-слайдер: эвристика без доступа к исходнику модуля Slider — при первом включении смотрите статус-лейбл; ни один Fake-клик вне зоны не используется.
- Магазин: покупки идут напрямую на сервер; денег не вернуть — проверяйте точное имя предмета как в клиенте (`Elder Worm` и т.п.).
