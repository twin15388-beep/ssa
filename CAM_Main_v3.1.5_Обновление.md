# CAM Main Hub — v3.1.5

Файл: **`CAM_Main_Hub_v3.1.1.lua`** (standalone, вставляется целиком в исполнитель).

## v3.1.5 (патч: фарм сам надевает оружие)
- **Прямой фарм снова экипирует оружие.** Движок нативного экипа (`ensureEquipment` — слоты тулбара, проверка Item_Equip-акнов, лимит 3 отклонений) остался в коде, но прямой фарм его не дёргал — отсюда «не надевает оружие и не бьёт». Теперь на каждом тике фарма цель сначала доводится до экипированного боевого инструмента, потом hold M1.
- На farm добавлен выбор **Weapon**: Auto combat tool (по умолчанию) / Keep equipped / Slot 1–5 (выбор уехал вместе с удалёнными вкладками — возвращён).

## v3.1.4 (патч: одна unload — в settings, без STOP-кнопки)
- **Unload одна, где она и была в lumen**: встроенная кнопка settings вернулась на место, наш «Unload hub» с farm-страницы убран.
- **Убрана кнопка STOP ALL и хоткей End.** Функции выключаются тем же тогглом, которым включались; аварийный stopAll остался в коде только как внутренняя защита (low HP / ошибки действий / kill-switch при диагностике).
- Никаких других изменений функционала.

## v3.1.3 (патч: фарм бьёт через hold M1, одна кнопка unload)
- **Атака при фарме — через Hold M1 (по умолчанию).** Raw `Combat_Service` стучал в сервер без гарантии регистрации удара (м плейбук шёл, урона могло не быть) — отсюда «не бьёт сам». Теперь в режиме по умолчанию хаб **зажимает левую кнопку мыши** (`mouse1press`/`mouse1release`, fallback VirtualInputManager) пока цель в радиусе (дистанция фарма + 8 стадов) — атака идёт через родной входной пайплайн игры, включая родные комбо. Цель умерла / ушла / защищается → кнопка отпускается; STOP / выключение тоггла / Unload отпускают её всегда.
- Вкладка farm получила выбор **Attack mode**: «Hold M1 (native)» (по умолчанию) или «Fast Attack (Combat_Service)» (режим 3.1.0–3.1.2).
- **Кнопка unload теперь одна** — осталась быстрая «Unload hub» на farm → hub; встроенная в settings (меню lumen) вырезана из сборки, чтобы не было двух.
- Мелкий фикс: при потере цели M1 отпускается сразу (раньше могла остаться зажатой до следующего появления цели).

Всё это вырезано из сборки — загружается только CAM Main. Автозагрузка сохранённых конфигов/тем сохранена (Lumen:Init вызывается теперь в нашей логике).

- Тёмная полоса справа на прошлых скринах — это игровая панель People (Reputation/Shrines) самой игры, не наш UI.

## Что нового

### 1. Auto Farm реально бьёт (порт из рабочего скрипта)
Фарм теперь работает напрямую, без цепочки «квест → маршрут → позиция»:

- **Auto Farm (mob names below / nearest)** — поиск ближайшего моба в `workspace.Humanoids.Regions` (не игроки, живые Humanoid'ы), подход с шагом ~2–40 стадов за тик, рядом — снап на позицию.
- **Mob names** (текстбокс, через запятую) — фильтр по именам; пусто = ближайший любой.
- **Auto Boss (source-backed boss names)** — фармит только боссов из встроенного списка 33 имён (извлечённые из контента игры). Посторонних мобов игнорирует.
- **Farm style**: Above / Front / Below / Behind + **Farm distance** (2–14) и **Farm height** (0–20) — позиция считается оффсетом от корня цели (как в рабочем скрипте: над/под целью переворачиваем up-вектор, чтобы не завалиться).
- **Farm speed** (20–150 стадов/с) — скорость подхода пошаговым телепортом; **Search range** (50–2000).
- **Farm noclip** (по умолчанию ВКЛ) — откл коллизии у частей персонажа, пока фарм активен.
- Удары — через тот же **raw `Combat_Service` FireServer** с циклом комбо 1..Max (рабочий протокол этого клиента), а не эмуляция ввода. Цели с активной защитой **пропускаются** (атрибут `NpcCounter` 1/2, ребёнок `NpcCounterTriggered`, `Blocking` без `PierceBlock`) — чтобы не крутить блок и не ловить отрицательный фидбек.
- Скорости обнуляются (`AssemblyLinear/AngularVelocity`) после каждого шага — цель «прилипает», без болтания.

### 2. Вкладки слипперы — стало компактно
- **УБРАНО**: Dashboard, Auto Level (кайтан), Farm (Селективная/Ближайший), Farm Position — этот функционал либо дублировался, либо заменён прямым фармом.
- Кнопки **Connect native controls** / **STOP ALL (End)** / **Unload Hub** переехали на вкладку Farm → секция hub.
- Live-статус «модуль загружен / нет» теперь на вкладке **Diagnostics**.
- **Settings страница назад** (встроенная lumen-страница с темами/конфигами/кейбиндами — кнопка есть в меню).

### 3. Смерть не выключает функции
Раньше при смерти персонажа срабатывал `stopAll` — все тогглы летели. Теперь при респауне только сбрасывается текущая цель фарма и кэши; **всё включённое остаётся включённым**.

### 4. Unload надёжный
`gui:Destroy()` обёрнут в pcall, cleanup идёт в правильном порядке, `Lumen:Unload` — с warn при ошибке. Тень под окном (из прошлой сборки — 3.0.0-fix) убрана навсегда, включая возврат после закрытия.
