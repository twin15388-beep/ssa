# CAM Main 2.2.0 — исправление ноклипа, нормальный ESP, наживка, чистка вкладок

**Основной файл: `CAM_Main_Hub_v2.2.0.lua`.** Выгрузи старый (Unload hub) и запусти новый. Старые версии не удалены.

## 1. Ноклип при фарме — исправлен

В 2.1.0 авто-ноклип был включён **постоянно**, пока работает фарм: на этапах ожидания/диалога цели нет, и персонаж проваливался сквозь пол — отсюда «частично поломан».

Теперь ноклип включается **только когда реально идёт перемещение** (к NPC, к точке спавна, удержание позиции у цели). Как только фарм стоит — коллизии обычные, падения сквозь карту нет. Режим ходьбы (**Walk**) ноклип не использует нарочно. STOP по-прежнему всё восстанавливает.

## 2. ESP переделан

Было: самодельные 2D-рамки с покадровой проекцией (глючили). Стало — стандартные мировые объекты:

- **Highlight** на модели (заливка+контур, видно через стены), цвет по типу: мобы оранжевые, боссы красные, NPC фиолетовые, сундуки золотые, лут зелёные и т.д.
- **Билборд над головой**: имя, HP, дистанция — одним тумблером «Text: name / HP / distance».
- **Health bar** — полоска HP в билборде.
- **Tracers** — линии от низа экрана (единственное, что рисуется покадрово).
- Скан раз в 0,45 с, лимит и дальность как раньше. Старые тумблеры Box/Fill/3D/Distance/Health-text убраны — их роль теперь играют Highlight и общий текст.

Быстрый старт: кнопка **Enable basic mob / boss ESP** на вкладке ESP.

## 3. Новая функция: наживка (fishing bait)

Вкладка **loot / interaction → fishing bait (native signal)**:

1. **Refresh bait list** — ищет в инвентаре предметы со словом «bait».
2. Выбери наживку в списке → **Equip selected bait**. Хаб шлёт родной сигнал игры `EquipBait` с id предмета (точно как клик в родном инвентаре).
3. Подтверждение — `Misc/EquippedBaitId`, счётчики в диагностике.
4. **Unequip bait** снимает (шлёт 0, как родной повторный клик).

Сам заброс/мини-игра рыбалки пока не подключены — это следующий шаг после разбора контроллера удочки.

## 4. Чистка вкладок

Убраны «водяные» пояснения из секций (было ~50 лейблов, стало ~20), удалены неработающие/устаревшие тумблеры стилей ESP, список «что не подключено» свёрнут в один лейбл. Функционал не пострадал.

## Проверка 2.2.0

Моки: ноклип не трогает коллизии без цели и включается при удержании; Highlight/билборд создаются и полностью удаляются; наживка проходит запрос→подтверждение→снятие. Вся прежняя приёмка (квесты, позиции, зелье, вотчдоги) — PASS. Синтаксис standalone — PASS.

**Live-проверка не проводилась.** Если ESP у части объектов не появится или наживка не подтвердится — пришли лог/ONE CLICK диагностику.
