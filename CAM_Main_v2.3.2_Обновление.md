# CAM Main Hub v2.3.2 — skill tree spend (последний крупный пробел закрыт)

Протокол захвачен живой записью probe v1.1 (26.09.2026, одна сессия ~14 секунд):
- **SignalFunction.ToServer("UnlockSkillTreeNode", "Max Health")** → сервер вернул `true`;
- Дельты: `SkillPoints` 29→13, `SkillPointsSpent/Max Health` 7→23, `SkillTreeUnlockedList/Max Health` 1→2 (остаток узла повышается, стоимость — 16 очков с ранга 1 на 2 в примере).

## Новое — раздел «skill tree (manual spend)» (вкладка v2.3 actions)
- Текстовое поле: точное имя узла (как в дереве, напр. `Max Health`).
- Кнопка «Unlock / level up node» → ровно один вызов `SignalFunction.ToServer("UnlockSkillTreeNode", имя)`. МНОГО-кликов в цикле нет — это трата реальной валюты (SkillPoints).
- Server-ack: через ~0.4 c читаются `SkillPoints`/`SkillTreeUnlockedList` — если очки упали и ранг вырос, уведомление «Points 29 -> 13, rank 1 -> 2».
- Отказ сервера (false): нет очков / предыдущий узел не закрыт / узел макснут.
- Индикатор рядом: текущие очки и ранг выбранного узла (обновляется каждый тик UI).

## Также в этой сборке
- Исправление сборщика: перенос новых хелперов в таблицу `actions` — превышен лимит Lua в 200 локальных переменных на функцию (сборка 2.3.1 падала бы с той же ошибкой после очередной фичи; 2.3.1\. выданная вам сборка валидна, но синтаксис-чек уже на гране).
- Pending-лист теперь только: code redeem UI (ни один code-протокол не найден), внутренняя математика queue/waves, gear scoring. «Instant kill / infinite stamina» — отклонены как server-side-authoritative.

## Файл/проверки
- `CAM_Main_Hub_v2.3.2.lua` — 280 439 байт, Lua 5.4 syntax PASS, SHA-256 `см. чат`.
- Свиты: v230 (5/5), v231 (6/6, включая новый skill-tree тест: точные аргументы + ack-уведомление), v2-регрессия зелёная.

## Как проверить в игре
1. Откройте дерево навыков, запомните точное имя желаемого узла и текущие очки.
2. Введите имя в поле, нажмите кнопку (подтверждение кликом).
3. Смотрите индикатор — очки упадут, ранг вырастет, уведомление придёт.

Если выведется «Server refused» — причина: нет очков или не закрыт предыдущий узел.
