# CAM Main Hub v2.4.1 — Rapid M1: максимум kill-speed, который вообще возможен с клиента

Ответ на «inf/insta kill»: урон считает сервер из характеристик оружия — напрямую его не подменить.
Но внимательный разбор основного боевого скрипта показал: **скорость свинга — полностю клиентская**.

## Доказательная база (по исходникам)
- `core_sources/003_Combat_presets.lua`: `Presets.Normal.default=0.26, default_before_hit=0.2, default_before_swing=0.2`, плюс поля `Last_Punched=0`, `Last_Combo=0`, `Is_Air_Combo=false` — обычная глобальная клиентская таблица модуля.
- `oneclick_sources/060_Main_Combat_Script_Client.lua:144-147`: ход свинга ставит `Combat_presets.Last_Punched=os.clock()`; сами задержки `u23/u27` берутся из `Presets`.
- Гейты (`core_sources/002_Checker.lua`) читают те же поля из того же модуля.

## Что делает тоггл «Rapid M1 pace (client swing unlock)»
1. По всему `Presets.*`: `default→0.05`, `default_before_hit→0`, `default_before_swing→0` (оригиналы сохраняются, STOP/выкл — текстово восстанавливает).
2. Каждый фрейм: `Last_Punched=0`, `Last_Combo=0` — клиентский гейт не троттлит свинги.
3. На выходе: свинги летят впритык друг за другом — каждый всё равно наносит ПОЛНЫЙ серверный урон вашего оружия; суммарный DPS умножается насколько позволит сервер.

## Честная граница
Если сервер повторно валидирует интервал между свингами, лишние `Combat_Service` будут тихо отброшены — тогда скорость упрётся в серверный лимит. Это проверяется только в игре. Даже в таком случае никаких паршивых накруток урона не происходит.
