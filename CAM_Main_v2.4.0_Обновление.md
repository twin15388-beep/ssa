# CAM Main Hub v2.4.0 — combat assist: inf stamina & inf dash (клиент-только, по исходникам)

Отвечает на: «где insta kill / inf stamina / inf dash». Всё проверено по декомпилированным скриптам.

## Instant kill — НЕВОЗМОЖЕН (доказано, не отказано молча)
`SignalEvent.ToServer("Combat_Service", weaponName, swingNum, runFlag, hitDelaySec, airFlag, override)` (`060_Main_Combat_Script_Client`, стр. 133). УРОНА среди аргументов НЕТ — сервер считает его сам по характеристикам оружия. Ни один клиентский ремот в дампах урон не передаёт. Доказательство лежит в разборе; ставить фейковый переключатель я не буду.

## Inf Stamina (client replica) — РАЗДЕЛ «v2.4 combat assist»
- Вывод из исходников: расход и реген стамины живут в клиенте (`007_Skills_Module` стр. 126: `Stamina.Value -= cost`, `014_StaminaComponent` твинит реген локально).
- Серверная проверка `Stamina.Value <= STAMINA_FLOOR` найдена только в двух скриптах: `298_Breathing_BoostServer` и `285_Hundred-Legged_ZigzagServer`.
- Хаб каждый кадр прижимает вашу клиентскую реплику `Values.Stamina` к `MaxValue` → все клиентские стамина-гейты (дэш, большинство скиллов, run) проходят всегда. Где сервер иногда валидирует — запрос будет тихо отклонён игрой.
- Никакой записи на сервер нет — аналог того, как сама игра редактирует это же значение.

## Inf Dash + no skill cooldowns (client)
- Вывод: кулдауны ведёт клиентский `manage_cd` через `PlayerProfile.skill_info[skill].lastUsed` (`004_manage_cd.lua`). Сервер дэша (`296_DashServer.lua`, 67 строк) — НЕТ ни проверок кулдауна, ни стамины: только выставление флагов i-frame/air и VFX.
- Хаб каждые 0.3 c обнуляет `lastUsed` во всех записях вашей клиентской копии `PlayerProfile.skill_info` (-9999) → дэш и любые скиллы/блоки жмутся без ожидания. Чейндж происходит через нативный модуль (как сама игра записывает туда) — без hookfunction.

## Честные границы
- Если на конкретный скилл у игры есть серверный ред-лимит, он молча отбрак. В дампах таких скриптов почти нет (за редкими `Config.WINDUP`/`EndLag` внутри отдельных умений).
- STOP отключает запись; обнулённые `lastUsed` восстанавливаются игрой при следующем использовании скилла.

1. Включить нужные тогглы в «v2.4 combat assist». Пошлите скилл/дэш — задержек/срезов быть не должно.
