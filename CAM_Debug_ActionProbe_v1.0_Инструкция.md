# CAM ActionProbe 1.0 — находим, КАК сделать оставшиеся функции

**Файл: `CAM_Debug_ActionProbe_v1.0.lua` (RightShift).** Это перехватчик действий: ты делаешь ОДНО действие руками, а он записывает, что при этом происходит в игре. По этим отчётам я допишу функции точно, без догадок.

## Что записывается

1. **Сигналы клиент→сервер**: каждый вызов `ToServer`-функций модулей связи (имя, аргументы, время) и **ответы** функций. Через `hookfunction`, если экзекьютор поддерживает (Potassium должен) — тогда ловятся даже вызовы из скриптов, которые запомнили функцию заранее.
2. **События сервер→клиент**: подписка на событийные таблицы модулей связи.
3. **Клики по кнопкам игры**: путь нажатой кнопки + время (кнопки самого пробника не пишутся).
4. **Изменения данных**: дельты Data/Values/Items_Config каждые 0,4 с (например `SkillTreeUnlockedList`, `EquippedBaitId`, здоровье — со временем).
5. **Целевой дамп**: скрипты по ключевым словам (skill/breath/fish/shop/train/queue/card/race/soul/deliver/parry...) — декомпилированный код прямо в отчёте.

Пробник ничего не покупает, не атакует, не меняет статы. При Unload всё восстанавливается.

## Порядок работы (для КАЖДОГО действия отдельный прогон)

0. Выгрузи main и старые debug (Unload), потом запусти пробник.
1. **«1) ATTACH taps»** — один раз после запуска. В статусе появится число taps (должно быть >0).
2. Нажми **«Scan keyword scripts + decompile»** (один раз достаточно за сессию).
3. Нажми кнопку **сценария** (см. таблицу ниже) — прочитай уведомление, что делать.
4. **«2) START recording»** → сделай действие руками → **«3) STOP recording»**.
5. **«STOP recording + SAVE + COPY report»** → файл `CAM_ActionProbe_<...>.json` в workspace + буфер. Пришли сюда.

Следующее действие — снова с пункта 3 (ATTACH не нужен повторно).

## Какие сценарии нужны (по приоритету)

| Что снимаем | Что делать руками | Что это даст |
|---|---|---|
| **Skill tree** | Открыть древо, разблокировать 1 доступный узел | Точный серверный запрос разблокировки → Auto Skill Tree |
| **Breathing trainer** | Выучить 1 ранг у тренера | Цепочка диалог→обучение → Auto Breathing |
| **Shop** | Купить САМУЮ ДЕШЁВУЮ вещь (парочка вен) | PurchaseFromShop вариант + ответ → Auto Buy с лимитом |
| **Fishing** | Наживка + заброс + поклёвка + мини-игра до конца | Полный цикл сессии → Auto Fish |
| **Training** | 1 полная тренировка (отжимания/медитация) | Признак успеха → Auto Training |
| **Queue/cards** | Join в очередь; если телепортнуло в мини-игру — запустить пробник ТАМ и пройти волну/выбор карты | Протокол очередей и карт |
| **Delivery** | 1 полная доставка | Цепочка доставки |
| **Race/Demon** | Диалог до шага ПЕРЕД необратимым подтверждением | Проверки смены расы (без списаний) |
| **Parry/block** | Агрессивный слабый моб, блок прямо перед его ударами ~5 раз | Корреляция блока и урона → Auto Parry |
| **Souls/cache/schematic** | Собрать по одному | Типы объектов и промпты |
| **Code** | Ввести 1 код | Сигнал погашения кодов |

## Важно

- **Один прогон = одно действие.** Не мешай несколько действий в одну запись — тогда отчёт не разобрать.
- Если после ATTACH в статусе `taps 0` — напиши, дам вариант под твой экзекьютор.
- Если при действии `signals` не растёт (смотри Refresh counts) — тоже напиши: значит скрипт локализовал функцию, сделаю обход.
- Запись сама остановится через 180 с.
- Отчёты можно снимать прямо во время боя/фарма — персонажем управляешь ты, пробник только пишет.
